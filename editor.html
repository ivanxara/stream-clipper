Ajuda e atalhos

Resultado: a roda do rato faz zoom da vista (para ver pormenores) e, com zoom, arrastar anda para os lados; duplo clique volta a ver tudo. Para mudar o enquadramento, clica primeiro numa zona (câmara, jogo, moldura…): aparece a moldura dela — arrasta dentro para enquadrar e usa os cantos (ou a roda dentro dela) para o zoom. Esc larga a zona.

Textos e imagens: arrasta para mover, cantos para redimensionar, ↻ para rodar. Duplo clique num texto (ou Enter) para o escrever diretamente no vídeo; Esc ou clicar fora termina.

Em «Adicionar elemento» → «Ficheiro», carrega imagens, GIFs ou vídeos MOV/MP4 e clica numa miniatura para adicionar ao visor. GIFs e vídeos repetem sem som durante o intervalo do elemento; a animação também fica na exportação.

Usa «+ Vídeo» para anexar um ou mais vídeos ao fim da faixa de vídeo, como clips normais (podes arrastá-los para outro sítio, cortar, dividir e duplicar); a junção dos ficheiros só acontece ao exportar. Para sobrepor um vídeo, usa «Adicionar elemento» → «Ficheiro». «+ Música» cria uma faixa de áudio; arrasta-a para posicionar, usa as extremidades para cortar e ajusta volume e fades no painel lateral.

Timeline: a faixa de vídeo é uma fila de clips encostados, como num editor normal. Clica num clip para o selecionar; arrasta-o para mudar de sítio; puxa as pontas para cortar (ou recuperar o que cortaste). Ctrl+B divide no cursor, Ctrl+D duplica o clip selecionado (uma cópia inteira logo a seguir), Delete apaga-o e o resto encosta. Início/Fim (I/O) cortam o clip debaixo do cursor até ao cursor. Com um texto/imagem/música selecionado, estas ações atuam nele. Zoom da timeline: − / + / Ajustar, ou Ctrl+roda. No botão direito de um clip há também «Abrir este clip noutra aba» e «Repor o vídeo completo».

No Streamer, arrasta a divisão verde para ajustar a altura da câmara.

No Desfocado e Original, usa «Zoom do vídeo» e os botões − / + no painel (ou clica no vídeo e usa a roda/os cantos) para aproximar até 400%. Arrasta dentro da moldura para enquadrar e usa «Repor enquadramento» para voltar ao início. O zoom fica no vídeo exportado.
